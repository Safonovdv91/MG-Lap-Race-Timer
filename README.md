# Проект MG-Lap-Race-Timer
Фотобарьер работающий на базе esp32-s3(или аналоги). Проектирование вед я создал проект, опиши мне подробную инструкцию по реализации схемы,
**MG-Lap-Race-Timer** — это система хронометража для спортивных мероприятий, использующая инфракрасные (ИК - TSAL6200, или аналог, Лазерный 940 нм) излучатель и фотодиод(BPW34, vishay ) для отслеживания времени круга и скорости. Система состоит из двух основных компонентов: **передатчика** и **приемника**, оба на базе микроконтроллера ESP32.

## Основные возможности

- **Измерение времени круга:** Точное отслеживание времени прохождения круга.
- **Измерение скорости:** Расчет скорости на основе времени пересечения луча.
- **Веб-интерфейс:** Удобный интерфейс для просмотра результатов в реальном времени, доступный с любого устройства с Wi-Fi.
- **Беспроводная телеметрия:** Передатчик отправляет данные о состоянии своей батареи на приемник.
- **Гибкая настройка:** Возможность изменения режимов работы и других параметров через веб-интерфейс.

## Архитектура

Система разделена на два устройства:

### 1. Передатчик (Transmitter)

- **Задача:** Генерировать постоянный ИК-сигнал или Laser-сигнал.
- **Функционал:**
  - ИК (LASER)-сигнал.
  - Измерение напряжения аккумулятора
  - Передача телеметрии(напряжение, вкл \выкл луч) по ESP-NOW на Receiver
  - Отображение заряда через LED
  - Hearbeat работы


 - **Принцип работы**
 - Шим сигнал ESP32 на GPIO13 D13 (частота 38кГц) через транзиcтор IRLZ44N.
  При duty = 50% использую х2 мощность(200мА) - TSAL6200



### 2. Приемник (Receiver)

- **Задача:** Обнаруживать пересечение ИК-луча и предоставлять интерфейс для пользователя.
- **Функционал:**
  - Создает точку доступа Wi-Fi.
  - Запускает веб-сервер, доступный по адресу `http://192.168.4.1`.
  - Регистрирует пересечение ИК(лазерного)-луча.
  - Рассчитывает время круга.
  - Отображает историю измерений.
  - Принимает и отображает данные телеметрии от передатчика.
  - Трансляция ESP-NOW с данными времени.

## Веб-интерфейс

Приемник предоставляет веб-интерфейс со следующими возможностями:

- **Выбор режима:**
  - **Секундомер круга (Lap Timer):** Измеряет время между двумя последовательными пересечениями одного датчика.
  - **Гоночный таймер (Race Timer):** Работает как стандартный секундомер, запускаемый первым датчиком и останавливаемый вторым.
- **Отображение данных:** Показывает текущее измерение, историю последних 5 измерений, а также состояние батарей приемника и передатчика.
- **Настройки:** Позволяет изменять расстояние между датчиками ( для режима спидометра) и настраивать параметры Wi-Fi.

## Аппаратное обеспечение

- **Микроконтроллер:** ESP32 DevKit V1 (или аналогичный).
- **Передатчик:** 
  - ИК-светодиоды(940нМ), laser излучатель.
  - Mosfet AO3400A, IRFL44N
  - TSAL6200. R1 = 100 Ом (Или из расчета пот току(обычно меньше 40мА)) В KY-008 не требуется.
- **Приемник:**
  - Светодиод BPW34 | Laser Detector | Vishay BPV10NF
  - Операционный усилитель - **LM358** / TLV2371 / OPA380.
  - Компаратор - **LM393** / LMV358
- **Обвязка:**
  - R:
    - 220 Ом
    - 2х 100 кОм
    - 1 МОм
  - C:
    - 0.1 мкФ 16В
    - 100 пФ
- **Источник питания:** 
  - Li-ion или Li-po аккумулятор. с повышающим модулем до 5В.
  - power boost li-ion -> 5В
  - Преобразователь 5В -> 3.3 В
  
### Схема подключения (пины)

#### Передатчик:

- `GPIO13 (D13)`: ИК-передатчик 1
- `GPIO34`: Датчик напряжения батареи(через делитель напряжения)

#### Приемник:

- `GPIO14`: ИК-приемник 1
- `GPIO34`: Датчик напряжения батареи(через делитель напряжения)

```
     (+) Батареи LiPo
           |
           |
         [ R1 ]  (1 МОм)
           |
           |---------------------> к пину GPIO 34 на ESP32
           |
         [ R2 ]  (300 кОм)
           |
           |---------------------> к пину GND (земля) на ESP32
           |
         [ C1 ]  (0.1 µF (100 nF) X7R 16 V или 25 V, керамика)
           |
            +---------------------> к пину GND (земля) на ESP32 (вторая нога конденсатора)
```

- `GPIO32 (D32)`: Светодиод статуса ( пересечения луча)
- `GPIO33 (D33)`: Светодиод режима измерений (запущен \ остановлен таймер)

## Сборка и прошивка

Проект использует [PlatformIO](https://platformio.org/).

1. **Установите PlatformIO Core** или [PlatformIO IDE for VSCode](https://platformio.org/install/ide?install=vscode).
2. Откройте проект в VSCode.
3. Для сборки и прошивки **передатчика** используйте команду:
   ```bash
   pio run -e transmitter -t upload
   ```
4. Для сборки и прошивки **приемника** используйте команду:
   ```bash
   pio run -e receiver -t upload
   ```

Элементная база:
esp32 devkit 30pin - основной модуль обработки логики, используется 
Точечный ИК-фотодиод Vishay BPV10NF для отслеживания пересечения луча
LM358P - усилитель сигнала луча
LM393N - компаратор для получения логического уровня и передача логического сигнала после сравнения с заданным сигналом и сигналом после LM358P
MT3608 - модуль заряда и питания, с выводом 5В. Запитан от LiIon21700 4500mAh
LM117T - если необходим можно использовать
Светодиоды для отображения логики(информация для отображения)

Подключение к ESP32:
GPIO13 - Выход LM393N
GPIO32 - светодиод 1
GPIO33 - светодиод 2
