# Архитектурный план проекта кругового таймера

## Текущее состояние

- В проекте излучатель и приемник ИК сигнала находятся на разных ESP32
- ИК или лазер передатчики работают на пинах GPIO 13(возможна запитка напрямую от питания 5В), но желательно через
МОСФЕТ транзистор иметь возможность управлять
- ИК приемники подключены к пинам GPIO 14
- Уровень заряда определяем через делитель напряжения GPIO 34

## Цель

Проект разделен на две независимые прошивки:

1. Излучатель (transmitter):
 - передача ИК сигнала или сигнала лазера
 - передача данных о заряде батареи(телеметрия излучателя)

2. Приемник (receiver):

  - прием ИК сигнала
  - веб-сервер для отображения данных
  - ведение секундомера пересечения
  - FEATURE: передача данных через ESP-NOW

## Коммуникация

- Используется Wi-Fi с UDP для связи между телефоном\ноутбуком
- Для связи с другими ESP использцется внутренний протокол ESP-NOW
- Приемник будет получать информацию о состоянии излучателя (например, уровень заряда батареи)
